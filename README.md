# 视频融合 (Video Fusion)

把 B站、抖音和红果短剧装进一个 App。

不用来回切换，不用忍受开屏广告，不用被推荐算法牵着走。
视频在应用内原生播放，不套网页。

---

## 为什么用它

**没有广告。** 播放器就是播放器。

**不套网页。** 视频在应用进程内解码，不是嵌一个浏览器窗口。

**不伪造数据。** 没登录就显示"登录后可操作"，不会假装你没点过赞。

**不静音失败。** 加载失败会告诉你卡在哪一步，不会转圈转到天荒地老。

## 界面

四个主页面，Apple 设计风格：

- **推荐** — 全屏竖滑短视频，滑到即播
- **发现** — 长视频网格 + 跨平台搜索
- **直播** — B站与抖音直播
- **我的** — 账号、收藏夹、稍后再看、观看历史

设置放在「我的」里面，因为没人会去设置里找自己的收藏。

深色播放区（画面需要纯黑背景），浅色外壳。

## 安装

从 [Releases](https://github.com/Hu-Yang-rui/video-fusion/releases) 下载 APK。

| 架构 | 适用设备 |
|---|---|
| `arm64-v8a` | 绝大多数手机（推荐） |
| `armeabi-v7a` | 老设备 |
| `x86_64` | 模拟器 |

Android 7.0 及以上。

---

## 登录

**B站**：App 内扫码登录。

**抖音**：导入浏览器 Cookie。
1. 电脑浏览器登录 [douyin.com](https://www.douyin.com)
2. F12 → Application → Cookies
3. 复制整段 Cookie
4. 粘贴到 App 的设置里

> Cookie 只存在你手机本地，不上传任何服务器。

## 从源码构建

需要 Flutter 3.47+ 和 Android SDK。

```bash
flutter pub get
flutter build apk --release --split-per-abi
```

跑测试：

```bash
flutter test --concurrency=1
```
